# Проект: Фильтрация заказов

## Описание
Проект позволяет фильтровать заказы через модальное окно. Пользователь выбирает статусы заказов, применяет фильтры, и список заказов обновляется. Есть пагинация, уведомления, валидация и красивый дизайн.

## Стек
- Vue 3 (Composition API)
- SCSS
- Figma (макет)

## Функционал
- Модальное окно с фильтрами (с анимацией).
- Валидация: нельзя применить фильтры, если ничего не выбрано.
- Пагинация для списка заказов.
- Кнопка "Показать все заказы".
- Уведомления об успехе или ошибке (с анимацией).
- Обработка ошибок при запросах.
- Адаптивный и красивый дизайн: тени, анимации, кастомный скроллбар.
